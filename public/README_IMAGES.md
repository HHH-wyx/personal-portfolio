# 图片文件说明

## 需要添加的图片

请将以下图片文件添加到 `public/` 目录：

1. **avatar.jpg** - 您的头像图片（建议尺寸：400x400px 或更大，正方形）
2. **project1.jpg** - 项目1的展示图片（建议尺寸：800x600px 或更大）
3. **project2.jpg** - 项目2的展示图片（建议尺寸：800x600px 或更大）
4. **project3.jpg** - 项目3的展示图片（建议尺寸：800x600px 或更大）

## 图片格式

- 支持格式：JPG, PNG, WebP
- 建议使用 WebP 格式以获得更好的性能
- 确保图片文件大小合理（建议每个图片 < 500KB）

## 占位图片

如果您暂时没有图片，可以使用以下占位图片服务：

- [Placeholder.com](https://placeholder.com/)
- [Unsplash Source](https://source.unsplash.com/)

例如：
- 头像：`https://source.unsplash.com/400x400/?portrait`
- 项目：`https://source.unsplash.com/800x600/?technology`
